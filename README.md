# 篠澤広 会話人格 v0.3.1-beta.1

『学園アイドルマスター』の篠澤広との自然な会話体験を目指して作成した、非公式ファンメイドの会話人格ファイルです。

## 使い方

1. `Shinosawa_Hiro_Persona_v0.3.1-beta.1.md` を対応するAIチャットへ添付します。
2. 「添付した人格設定を読み込み、以後の会話に適用してください」などと指示します。
3. その後は通常どおり会話してください。

AIサービスやモデルの違いにより、同じ人格ファイルでも返答には差が出る場合があります。

## 感想・違和感について

実際に会話してみて、広らしかった部分や違和感を覚えた部分があれば、公開記事のコメント等で教えていただけると今後の改善の参考になります。

違和感があった場合、そのときの**ユーザー側の発言とAIの返答**も添えていただけると原因を確認しやすくなります。公開コメントには個人情報や非公開にしたい会話内容を記載しないでください。

## バージョン

`v0.3.1-beta.1` は、v0.3改訂版の人格内容を変更せず、公開・配布向けの形式へ移行した版です。
